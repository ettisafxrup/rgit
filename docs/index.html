Why rgit

Spend your time on code, not on git plumbing

git is powerful, but the daily routine is a lot of typing. rgit does that routine for you, the way an experienced developer would.

Ship in one command

rgit push replaces init, remote add, add, commit, pull and push. It only asks when your answer matters.

Safe by default

Your local work is never lost. rgit asks before anything destructive and warns you before you rewrite history that is already pushed.

Truly cross-platform

A native app for Windows, Linux and macOS that works the same in Command Prompt, PowerShell, Git Bash and every Unix shell.

Powered by real git

rgit uses the git you already have. Your logins, SSH keys, hooks and settings keep working exactly as before.

Less typing

Features

Everything for the everyday workflow

Focused commands that cover the daily routine, from your first commit to a tidy branch list.

Pull & sync

Pull without losing your uncommitted work. rgit sync brings a branch fully up to date in both directions.

Status at a glance

See your branch, what there is to push or pull, the last commit and every change on one clear screen.

Undo without fear

rgit undo takes back your last commit but keeps every change, ready for you to fix and commit again.

Branching made simple

Create branches, switch from a list, rename them everywhere at once, and clean up branches that are already merged.

Project scaffolding

Generate a README, a LICENSE, a .gitignore and a project tree in seconds.

Built-in doctor

rgit doctor checks your setup and tells you exactly how to fix anything that is wrong.

GitHub shortcuts

Clone with owner/repo and open the current branch in your browser with rgit open.

Friendly everywhere

rgit suggests the right command when you make a typo, gives you help for every command, and has a --yes mode for scripts.

FAQ

Frequently asked questions

Does rgit replace git?

No. rgit is a companion that runs the git already installed on your computer. You can keep using plain git side by side, and everything rgit does shows up in your normal git history.

Will my logins, SSH keys and settings still work?

Yes. rgit calls git directly, so credential helpers, SSH keys, hooks, aliases and every setting work exactly as before.

Is it safe to use on important repositories?

Yes. Pulls keep your uncommitted work safe, rgit asks before staging or deleting anything, undo keeps your changes, and a remote branch is only deleted after its new name has been pushed.

Windows says “Windows protected your PC”. Is that normal?

Yes, it appears for new apps that are not yet widely downloaded. Click More info, then Run anyway. You can check your download against SHA256SUMS.txt from the release.

macOS says the app “cannot be opened”. What should I do?

Run xattr -d com.apple.quarantine /usr/local/bin/rgit once. The one-line install command does this for you automatically.

Do I need administrator rights?

No. On Windows, choose “Install for me only”, or use the portable program. On Linux and macOS, the install command uses ~/.local/bin when it can't write to /usr/local/bin.

How do I uninstall rgit?

On Windows, go to Settings → Apps → rgit. On Linux and macOS, delete the file, for example sudo rm /usr/local/bin/rgit.
