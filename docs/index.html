Why rgit

Spend your time on code, not on git plumbing

git is powerful, but the daily routine is a lot of typing. rgit does that routine for you, the way an experienced developer would.

Ship in one command

rgit push replaces the whole routine of init, remote add, add, commit, pull --rebase and push. It asks only when it matters.

Safe by default

Rebases with autostash so local work is never lost. It warns before rewriting pushed history and never deletes a remote branch until its replacement is pushed.

Truly cross-platform

A native executable for Windows, Linux and macOS. It works the same in Command Prompt, PowerShell, Windows Terminal, Git Bash and any Unix shell.

Powered by real git

rgit drives the git you already have installed. Your credentials, SSH keys, hooks, aliases and configuration all keep working, and nothing is reinvented.

Less typing

Undo without fear

Command reference

21 commands, zero guesswork

FAQ

Frequently asked questions

Does rgit replace git?

No. rgit is a companion that runs the git already installed on your computer. You can keep using plain git side by side, and everything rgit does is visible in your normal git history.

Will it use my existing credentials, SSH keys and settings?

Yes. rgit calls git directly, so credential helpers, SSH keys, hooks, aliases and every configuration option work exactly as before.

Is it safe to use on important repositories?

rgit is built around safe defaults. Pulls use --rebase --autostash, it confirms before staging or deleting, undo keeps your changes, it warns before rewriting commits that are already pushed, and a remote branch is only deleted after its new name has been pushed.

Do I need administrator rights on Windows?

No. Choose “Install for me only” in the installer and rgit installs into your user profile. If you prefer, you can use the portable executable without installing anything.

macOS says the binary “cannot be opened”. What should I do?

Binaries downloaded manually are quarantined because they are not notarized. Run xattr -d com.apple.quarantine /usr/local/bin/rgit once. The one-line install script does this for you.

Can I use it in scripts and CI?

Yes. Pass --yes to accept every default without prompting, and set NO_COLOR=1 or pass --no-color for plain output. Exit codes are 0 for success, 1 for an error and 2 for invalid usage.

I used rgit 1.x. How do I upgrade?

Run the new installer. An all-users installation removes the old shell-based version automatically. A per-user installation reminds you to remove it from Settings → Apps. Your commands keep the same names.

How do I uninstall rgit?

On Windows, use Settings → Apps → rgit. This also removes rgit from your PATH. On Linux and macOS, delete the binary, for example sudo rm /usr/local/bin/rgit.
