## 🤔 What is rgit?

Saving and sharing your work with git usually takes many commands, and it's easy to forget one.
**rgit does it all for you in one step**, and it asks before doing anything important.

```text
$ rgit push "Add dark mode"
 ✓ Committed 4f1e02f Add dark mode
 ✓ Pushed main to origin/main
```

## 🧐 Features

- **One command to save and share.** `rgit push` saves your changes and uploads them.
- **Stay up to date.** `rgit pull` and `rgit sync` get your team's latest work without losing yours.
- **See everything at a glance.** `rgit status` shows what changed on one clear screen.
- **Undo mistakes.** `rgit undo` takes back your last save and keeps your work.
- **Easy branches.** Create, switch, rename and clean up branches in seconds.
- **Project files in a snap.** Create a README, a license and an ignore list instantly.
- **Built-in checkup.** `rgit doctor` finds setup problems and tells you how to fix them.
- **Works everywhere.** Windows, macOS and Linux, in any terminal.

## 🕊 Installation

### 🪟 Windows

1. Download **[rgit-windows-x64-setup.exe](https://github.com/ettisafxrup/rgit/releases/latest/download/rgit-windows-x64-setup.exe)**.
2. Open it and follow the steps. Keep **“Add rgit to the PATH”** ticked.
3. Open a new terminal and type `rgit doctor`.

### 🍎 macOS

Open **Terminal** and paste:

```bash
curl -fsSL https://raw.githubusercontent.com/ettisafxrup/rgit/main/scripts/install.sh | sh
```

### 🐧 Linux

Open a terminal and paste:

```bash
curl -fsSL https://raw.githubusercontent.com/ettisafxrup/rgit/main/scripts/install.sh | sh
```

> rgit needs [git](https://git-scm.com) installed on your computer.
> For every command and option, see the **[documentation](https://ettisafxrup.github.io/rgit/docs.html)**.
